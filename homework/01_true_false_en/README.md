Run `bash build.sh` with XeLaTeX and DejaVu Sans installed. In Overleaf upload
this whole folder, select XeLaTeX and `true-false.tex` (or `solutions.tex`) as
the main document. The complete ZIP contains all sources and PDFs.

This is the true/false section being developed for the two-lecture homework,
not the full 120-minute mock or its assessed second part. No final point
allocation has been assigned. The earlier published homework draft is unchanged.
Question 6 is deliberately easy. Question 5 explicitly uses a non-strict local
maximum. Question 3 has a strictly positive domain. The proof of question 10
establishes uniqueness without assuming it inside Roy's identity.
