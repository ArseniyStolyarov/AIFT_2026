# Полный текст первой лекции

54 основных слайдов и 10 слайдов приложения, с учётом Кондорсе на слайде 20.
Русский текст для подготовки преподавателя; презентация остаётся английской.
Включены объяснения, переходы, вопросы, ответы, доказательства и семь рисунков.
Серые заметки — подсказки преподавателю, их не нужно произносить.

Сборка из этого каталога: ./build-speaker-script.sh

Нужны XeLaTeX, fontspec, polyglossia, математические пакеты, DejaVu Serif и
DejaVu Sans. Результат: lecture01-speaker-script.pdf. Все PDF-рисунки и логотип,
на которые ссылается исходник, включены в архив speaker-script-latex.zip.
Сеть и секреты для сборки не нужны.
